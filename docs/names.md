# Name candidates

**Working name: Aporia** (decided as a placeholder). It is authored in one place only,
`packages/brand/brand.json`, so switching costs one edit.

**Style** (your preference): short Greek or philosophical concepts about *how understanding
happens*, so it sounds like serious software and the learner is the one doing the work.

GitHub check (October 2026): stars of the largest repo with that exact name.

| Name | Meaning | Biggest same-name repo | Notes |
|---|---|---|---|
| **Aporia** (current) | The productive puzzlement before understanding (Socrates) | ~380★ (AI-related) | Distinctive. The collision is a small project, which is a minor issue, not a blocker |
| **Mathesis** | Greek μάθησις, literally "learning", "the act of coming to know" | ~33★ (logic library) | The most literal fit and almost free. Sounds like serious software. *My top alternative* |
| **Synesis** | "Understanding": putting pieces together into insight | ~11★ | Soft and modern-sounding, and almost free |
| **Elenchus** | Socratic questioning that exposes what you don't yet know | ~9★ (one LLM workspace) | Exactly what the tutor does. Harder to pronounce |
| **Phronesis** | Practical wisdom: knowing how, through doing | ~3★ | Fits "learn by building". A bit long |
| **Noesis** | The act of grasping something with the mind | ~54★ (robotics toolbox) | Short, but an "agent framework" uses it too |
| **Techne** | Craft knowledge, the skill of making | ~105★ (AI-agent skills) | Fits coding projects best, but it's crowded in the AI space |
| **Mneme** | Memory (one of the original Muses) | ~140★ (two projects) | Fits spaced review, but it's only one part of the app |
| **Anamnesis** | Learning as recollecting what you can work out yourself (Plato) | ~900★ | Too long, and taken |
| **Maieutic** | Socratic "midwifery": helping someone deliver their own idea | ~2★ | The most accurate metaphor, but an awkward word |
| **Paideia** | The full formation of a person through education | ~90★ | Broad, slightly grand |
| **Episteme / Metis / Kairos** | Knowledge / cunning wisdom / the right moment | 1k–3k★ | Taken by sizeable projects |

**Shortlist:** Aporia (keep) or **Mathesis**, with **Synesis** as a third option. Before the
first public release: check the domain, npm, and trademark.
