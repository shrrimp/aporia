# Font licences

The font files in this folder are **not** covered by the project's AGPL-3.0 licence.

| Font | Files | Owner | Licence |
|---|---|---|---|
| Satoshi | `satoshi/*.woff2` | Indian Type Foundry | [ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl): free for personal and commercial use, including embedding in applications. The fonts may not be sold, redistributed on font platforms, or modified and redistributed under another name. |
| Sentient | `sentient/*.woff2` | Indian Type Foundry | ITF Free Font License (same terms) |
| Pixelify Sans | via the `@fontsource/pixelify-sans` npm package | The Pixelify Sans Project Authors | SIL Open Font License 1.1 (shipped with the package) |

Both ITF families are published on [Fontshare](https://www.fontshare.com). If you fork this
project and are unsure the ITF terms fit your use, delete `satoshi/` and `sentient/`: the
stylesheet falls back to system fonts.
